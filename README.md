# IT Green Consulting — Website

Company website for IT Green Consulting (static site), deployed on Vercel from this repo.

- Plain HTML/CSS/JS — no build step. `index.html` is the home page; each service has its own page.
- `build.py` regenerates the pages from shared templates; `deploy.py` is the legacy direct-upload deploy helper.
